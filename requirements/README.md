# Miljö och versionskrav

Python-, Java-, R5- och GDAL-versioner är ännu inte låsta. Kompatibilitet och versionskrav ska fastställas innan applikationen byggs och beroenden installeras.

Inga paketlistor eller installationssteg finns ännu. `scripts/check_environment.ps1` rapporterar tillgängliga verktyg utan att installera eller ändra miljön. Kontrollen omfattar Python, Java, Git och GDAL; R5 kontrolleras inte ännu.
